# Building scenes for V02

You are animating one chapter of a narrated motion-graphic film for *Inside the GPU*. The narration
and storyboard are in `script/<chapter>.json`. The voice is generated by `tools/tts.py` and
`build/timing.json` tracks beat and word boundaries.

Each scene is its own file, `scenes/<scene>.js` (e.g. `scenes/ch01_s01.js`), registering one `V.scene(...)`
that animates that scene's storyboard in sync with the voice. Builders shared across a chapter go into
`scenes/<chapter>_common.js`, loaded automatically before the scene files.

The engine reference is `video/engine/engine.js`. The visual exemplar for style and choreography is
`v01/scenes/ch01_s01.js` and `v01/scenes/ch06_s02.js` (GPU package).

## The loop you work in

```bash
python3 tools/build_icons.py                          # after adding icon ids
python3 tools/render.py video/v02 stills ch01_s01      # stills at beat bounds + contact sheet
python3 tools/render.py video/v02 audit ch01           # automated layout audit
```

Stills land in `video/v02/build/stills/<scene>/` and `<scene>_sheet.jpg`.
Audit checks for text collisions, out-of-bounds text, and font sizes < 20 px.

## Art Direction

- **Colors:** amber (`compute`), coral (`bytes`), teal (`helps`), blue (`struct`), violet (`contrast`).
- **Typography:** Inter for headings/labels, JetBrains Mono for numbers/code.
- **Framing:** 1920×1080. Keep critical text within safe region `(96, 110)` to `(1824, 1000)`.
- **Takeaway:** Single clean line at bottom `y ≈ 952` using `S.takeaway`.
